# SimPT60 既有教授及专家意见闭合审查

审查对象：`SimPT60_submission_en.md`、`SimPT60_submission_en.tex` 与其 Word 转换稿。审查日期：2026-09-21。

## 证据范围

当前工作区和历史任务中没有保存三封教授邮件的完整原文。可恢复材料包括：一组明确关联教授沟通的论文定位意见、一次针对现稿前身的系统审稿，以及一组早期 60 kV 候选拓扑论文意见。后者针对不同论文对象，仅在仍适用于 SimPT60 时纳入。本审查不把无法恢复的邮件内容伪装成已核对事项。

## 结论

现稿已经闭合大多数科学与叙事意见，但还不能称为“全部满足”。科学定位、连续时序、验证层级、敏感性、拓扑统计、代理占比、版本差异和 N−1 定义均已显著补强。投稿管理方面仍有三个明确缺口：正式数据 DOI／持久仓库入口、作者与单位信息、独立的 Data Availability 与 Code Availability 声明。

## 已满足

1. **公开数据派生模型的边界前置。** 摘要最后一句明确说明 SimPT60 是 public-data-derived research model，且未作为运营商设备级模型验证；§4 开头、§4.7 和结论再次限定用途。
2. **不再把收敛等同于准确性。** §4 将完整性、收敛和功率平衡归为内部计算一致性；§4.7 明确禁止将收敛和筛查计数解释为设备级准确性。
3. **不再依赖选择性的两周或 336 个案例。** 主数据现在包含 31,492 个连续 15 分钟案例，覆盖 2025-05-01 至 2026-03-24，并处理夏令时重复小时和缺失区间。
4. **外部证据的依赖关系已说明。** §4.1、§4.4 和 §4.5 区分共享来源、弱空间代理和非独立节点真值；不再把 REN/E-REDES 汇总对照写成设备级验证。
5. **拓扑验证超越总长度。** §4.2 报告连通分量、活动母线与线路、简单图 cycle rank、节点度数和分电压长度背景；130 kV 七条线路的小样本限制已写明。
6. **增加了更贴近网络重建的验证。** §4.5.1 给出 394 座变电站的五折整站留出试验，并比较全局容量、地理邻站和网络邻站。
7. **参数、空间分配和运行代理敏感性已覆盖。** §4.3 包含线路、变压器、边界、发电和剩余负荷分配扰动；Supplementary Table S7 被正文明确引用，用于无功限值、PV 目标、补偿、电抗器和分接控制消融。
8. **热点不稳定性已正面呈现。** §4.3 报告最低 Top-20 Jaccard 为 0.429，并引用 Supplementary Figure S1 的热点持续频率，不再仅依赖全网 Spearman 相关。
9. **代理功率占比已量化。** §4.6 按月说明直接观测负荷、PDIRT 剩余分配和全国发电代理的占比，并指出电池与其他火电的高代理月份。
10. **静态资料日期与案例日期关系已解释。** §2.2.3 和 Table 4 区分来源日期、投运状态证据、冻结静态状态和未知日期处理。
11. **版本与数字差异已显式解释。** §3.6 明确 CORE-3783 与 N1-3787 的 4 个母线差异，以及 Estoi 从一个合并对象拆成三个并联等值后变压器从 228 行增至 230 行。
12. **N−1 故障集合与增量判据已收紧。** §5.2 给出 1,421 个线路回路组和 228 个变压器组，Table 11 表注解释最大净出口的 8 个非孤岛新增违规；正文引用 Supplementary Table S8 和 Note S4 说明排除规则与既有违规恶化。
13. **来源追踪与发布版本已进入正文。** §3.5–§3.6 给出 `SimPT60-2026.09.21-r1`、manifest、SHA256SUMS、环境和复现入口的组织方式。
14. **早期 60 kV 候选拓扑意见中仍适用的部分已吸收。** 现稿使用 evidence/status/provenance 字段、保守处理未知来源，并明确 OSM 语境不是独立运营商真值。

## 部分满足

1. **标题没有直接写 open-data-derived。** 当前标题简洁并符合用户选择；摘要首段和结论已补足边界，因此属于可接受的部分满足。若期刊编辑特别担心现实电网暗示，可在副标题或摘要首句继续强调 reconstructed from public sources。
2. **设备级拓扑真值仍不可获得。** 现稿加入结构统计和整站留出，但没有同期运营商接线、逐线路潮流或随机设备人工真值审计。论文已把它写成适用边界，不能把缺失证据标成已验证。
3. **边界分配敏感性有正文表述但依赖补充材料。** §4.3 把 boundary uniform 和 boundary voltage 纳入扰动；投稿包必须同时提供所引用的 Supplementary Table S6，否则读者无法复核完整结果。
4. **复现发布声明存在，但外部可访问性尚未完成核验。** 当前正文描述冻结版本和仓库结构，尚未看到正式版本 DOI 或匿名审稿访问链接。

## 尚未满足的投稿项

1. **正式数据 DOI／永久版本链接。** 当前英文稿没有 Data Availability 段，也没有可解析的 SimPT60 数据 DOI。旧 PT60-Candidate 的 Figshare DOI 不能替代当前 60–400 kV SimPT60 发布。
2. **Code Availability。** 正文虽提到 repository 和复现入口，但未单列代码 URL、不可变 tag/commit、许可证、环境锁文件和最小命令。
3. **作者与责任信息。** TeX 的 `\\author{}` 仍为空；作者、单位、通讯邮箱、ORCID、CRediT、资助、致谢和利益冲突声明尚未填写。若当前文件是匿名送审稿，空作者可暂时保留；正式投稿元数据仍必须准备。
4. **补充材料随稿可用性。** 主文多次引用 Tables S1–S8、Figure S1 和 Notes S2–S4。由于用户要求主文在 References 后结束，这些内容应作为单独 Supplementary Information 文件提交，而不能缺席。

## 不再适用的旧意见

早期 PT60-Candidate 论文关于 216 个候选配置的评分权重、保留与未保留线路账本、`confidence_score` 命名、GraphML 不能直接潮流计算、OSM concordance 分类等意见，针对的是仅 60 kV 的候选拓扑数据产品。当前 SimPT60 是 60–400 kV、含连续 AC 潮流案例的不同数据论文，不应把这些旧结构机械加入现稿。
