Scientific Data submission package

Main source: SimPT60_submission_en.tex
Main review PDF: SimPT60_submission_en.pdf
Editable manuscript: SimPT60_submission_en.docx

Compile the TeX file with XeLaTeX twice. The manuscript is self-contained and does not require supplementary information. It contains its numbered Nature-style references directly and does not require a .bib or .bbl file. Author information and author declarations remain intentionally absent for final completion by the authors.

The main text contains seven figures and seven tables. The seven figure PDFs in figures_final are the only external artwork required by the TeX source.
