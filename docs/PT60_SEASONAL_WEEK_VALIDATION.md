# PT60 夏冬连续周验证记录

> 本文下方数值保留第一次两周计算，属于修订前基线。接入核验和实际有功聚合去重后的最新结果、来源及敏感性实验见 [修订记录](PT60_SEASONAL_REVISION_LOG.md)。最新结果保存于 `portuguese_hv_network/outputs/temporal_validation/seasonal_revision/`：336 个修订时点全部收敛；夏冬 MAE 为 78.5 / 146.5 MW，原冬季热点在原峰值时刻由 136.7% 降至 49.6%，全网仍有其他阈值触发线路。

## 1. 目的与范围

本实验检查 PT60 在夏季和冬季连续运行条件下的交流潮流可解性、系统级功率平衡误差及代理线路压力；它由逐小时独立稳态潮流组成，不是动态仿真，也不包含储能荷电状态等跨时段约束。

REN 全国负荷和分能源发电总量是模型输入，REN 葡西净交换没有参与潮流求解而用于事后比较，因此净交换误差主要反映功率平衡闭合、模型网损和公开数据统计口径的共同差异，不能单独证明内部支路潮流真实。

## 2. 日期选择

日期在查看模型误差前按季节位置、自然周和 E-REDES 公开数据覆盖确定：

| 季节 | 连续周 | 采样 | 拓扑状态 | PDIRT 权重 |
|---|---|---:|---|---|
| 夏季 | 2025-07-07 00:15 至 2025-07-13 23:15 UTC | 168 个逐小时时点 | 7 个葡西边界母线、9 回路 | SUMMER |
| 冬季 | 2026-01-19 00:15 至 2026-01-25 23:15 UTC | 168 个逐小时时点 | 7 个葡西边界母线、9 回路 | WINTER |

两个连续周都早于 2026-07-02 北部葡西 400 kV 互联投运日期，因此没有把新增互联倒填到历史场景。夏季采用静态夏季额定值，冬季采用相对夏季额定值 1.15 的季节代理。

## 3. 数据来源与处理

- E-REDES 五个分区的变电站 15 分钟负荷记录提供节点负荷空间分布；本实验每小时读取 `HH:15` 时点。
- REN `ElectricityProductionBreakdownDaily` 提供同期全国负荷、储能用电、分能源发电和葡西进出口曲线。
- REN RNT 月度物理平衡提供月度网损参照，夏季使用 2025-07，冬季使用 2026-01；该指标与单小时模型网损并非严格同口径真值。
- PDIRT 2025–2034 附件 12 的季节及负荷制度权重用于分配 REN 与 E-REDES 之间的全国负荷残差。
- Open-Meteo 历史数据仅作为天气背景，不用于线路动态增容。

两个连续周的净交换误差全部为正。因为模型净进口等于模型负荷、发电与计算网损的平衡结果，而 REN 的负荷、发电及进出口曲线存在约 2.2–25.5 MW 的同步统计平衡残差，所以该正偏不能全部解释为线路参数误差。

## 5. 线路压力解释

夏季最大值出现在 2025-07-07 14:15 UTC，`LINE:003702` 达到 130.4%；冬季最大值出现在 2026-01-21 17:15 UTC，`LINE:000884` 达到 136.7%。两条线路均为 60 kV，且 `max_i_ka` 状态均为 `VOLTAGE_CLASS_ENGINEERING_PROXY`。夏季最常成为全网最高负载线路的是 `LINE:003702`，冬季则是 `LINE:000884`。

因此这些结果能够证明模型在连续压力变化下仍可求解，并能定位对输入假设敏感的候选瓶颈；它们不能证明真实电网发生了同等程度的过载。最优先的修复对象是上述 60 kV 线路的公开额定值、回路数和负荷挂接位置。

## 6. 可以支持的结论

1. PT60 在两个预先选定的连续自然周、共 336 个逐小时断面中全部完成交流潮流求解。
2. 模型与 REN 葡西净交换之间存在稳定正偏，夏季平均约为负荷的 1.14%，冬季约为 1.71%；冬季误差更大。
3. 连续周揭示了单点快照无法显示的昼夜与工作日/周末差异，也暴露了多小时持续的 60 kV 代理额定值压力。
4. 结果支持“可复算的公开交流潮流基准”定位，但不足以支持“调度中心级物理孪生”或“支路潮流已由实测验证”的表述。

## 7. 主要限制

- E-REDES 直接记录平均只覆盖 REN 全国负荷的约 70%–73%，其余负荷仍通过 PDIRT 权重分配，节点级潮流存在明显空间代理成分。
- 冬季 E-REDES 每小时记录数有波动，夏冬差异同时包含数据覆盖差异，不能全部归因于季节。
- 线路超限集中在额定值缺少逐线路公开证据的 60 kV 支路；当前只能作为模型诊断和数据修复优先级。
- REN 月度 RNT 网损比模型相同近似范围高约 1.29–1.41 个百分点，但时间窗口、网络边界和统计口径并不完全一致。
- 336 个时点属于两条相关时间序列，不应表述为 336 次独立重复实验。
- 公开资产缺少完整的历史退役和网络切换记录，历史案例仍受当前可见资产与拓扑回溯能力限制。

## 8. 可复现入口与结果文件

运行命令：

```bash
python portuguese_hv_network/src/run_seasonal_week_panel.py --restart-failures
```

结果位于 `portuguese_hv_network/outputs/temporal_validation/seasonal_weeks/`：

- `seasonal_week_validation.csv`：336 个逐小时时点的原始模型与观测指标；
- `seasonal_week_daily_summary.csv`：14 个自然日的聚合结果；
- `seasonal_week_summary.json`：两周汇总、日期选择规则与解释范围；
- `seasonal_week_failures.csv`：失败时点，当前仅含表头，表示无未解决失败。

运行器按时点增量保存并跳过已完成结果；公开 API 瞬时失败会显式记录，使用 `--restart-failures` 只补跑失败时点。运行过程中还修复了两个泛化问题：PDIRT 夏冬权重不再依赖案例名称中的 `SEP02`，REN 请求使用当前网关可接受的 `date, culture` 参数顺序，并为公开 API 增加有限重试。
